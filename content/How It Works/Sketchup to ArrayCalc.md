## Export
1. Export 할 면 선택
2. 확장 → d&b ArrayCalc Exchange → Export
	![[Pasted image 20260506111307.png]]
3. 세부 사항 설정
	**Listener height** : 청취자의 귀 높이 (기본값 1.2m)
	**Create a venue element name based on the** : Venue 에 표시될 면의 이름
	레이어(태그) 이름 기준, 그룹/컴포넌트(권장x) 이름 기준 선택 
	**Join elements by layer/group** : 같은 레이어/그룹의 면들을 하나의 요소로 합쳐서(Join) 내보낼지 여부
	![[Pasted image 20260506111443.png]]
4. 베뉴 파일 저장
	###### 유의할 점
	- 저장할 폴더 경로에 한글 없어야 함
	- Export 파일 이름 영어로
