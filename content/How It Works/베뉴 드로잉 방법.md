## 1. CAD 도면 정리
> 정리하지 않고 스케치업에서 작업 시 무거울 수 있고 디테일하게 작업하기 어려울 수 있음.

아래의 우선순위 별로 작업. 하위 번호로 갈수록 안해도 됨

0. 안쓰는 레이어 동결 (너무 무거워서 아무것도 못할 때만)
1. 필요 없는 선 삭제
2. 블록 해제
3. 해치 삭제(filter 활용)
4. 문자 삭제(filter 활용)
5. overkill, purge
6. (필요시) 선 따기

#### ❗만약 도면이 pdf라면?
- CAD → 가져오기 → 배율 맞추기
	1. 전체 선택 - Ctrl+A 
	2. 스케일
		SC→기준점 선택(0,0 입력)→R→기준선 끝과 끝 선택→숫자 입력
	3. Z(줌)→A(전체 보기)->Ctrl+S

## 2. Sketchup 에서 불러온 후 그림 그리기

> [[Sketchup 기본 세팅]]이 되어있다는 가정 하에 진행한다.

### 잠깐! 꼭 명심할 것
- 축을 기준으로 그림 그려야 함
	- 방향키로 축 고정 가능
	- 방향키로 축 활성화 → 마우스를 원점에 → 축에 정확히 스냅됨.
- 면이 1000개 이상 넘어가면 Export 불가.
- 호 그린 후 커브 분해
- d&b는 4각형 까지만 인식 가능. 4각형 이하로 면 나눠주기
- d&b는 한글 파일, 폴더 인식 불가.

### 드로잉 준비
1. 건축-밀리미터 선택
2. 평면도 가져오기
3. 저장
4. 무대 끝 중앙에 원점 맞추기 (개체 선택→이동)
5. 객석 방향 맞춰 회전 (d&b 빨강축에 객석, JBL 녹색축에 객석)
6. 단면도 가져오기
7. 개체 회전 후 원점 맞추기
8. 레이어 전체 선택 후 우클릭→태그 삭제
9. ‘CAD 단면, CAD 평면, Drawing’태그(레이어) 생성
10. Drawing 레이어 연필 표시
11. 각 도면 선택 후 태그 설정
12. 그림 그릴 단면의 태그 (평면도, Drawing) 제외 눈 감기

### 이제 그림을 그려봅시다
1. **평면도 라인, 면 그리기** - 라인, 사각형, 호 도구 활용
	- 첫 선 그린 후 그룹
	- 그룹 더블 클릭 또는 우클릭→그룹 편집 후 마저 그림 그리면 주변 선이 흐리 표현되어 편함
	- 기울기 없는 것들은 평면에서 면 생성
	- 기울기 있는 것들은 평면에서 앞 라인만 따서 가이드 라인 그린 후 단면에서 면 생성, 따라가기 활용
	- 절반 또는 1/4만 그린 후 대칭 이동 하는게 좋음
2. 라인을 다 그렸다면 **단면도 활성화**
3. 기울기 있는 부분 **면 그리기**
	- 그룹으로 그린 후 따라가기 할 때는 그룹 풀기.
	- 면과 가이드 라인이 한 그룹에서 또는 그룹 밖에서 닿아야 따라가기 가능
4. 따라가기로 **입체 면 생성**
	`가이드 라인 선택 → 따라가기 도구 선택 → 면 클릭`
5. 기울기 없는 부분 **면 올리기** (Push 도구)
	#tip 한 번 면 올린 후 다른 면 더블 클릭하면 같은 높이로 올라감
6. 그림 다 그린 후 면의 용도별로 **태그 생성**
	e.g. Stage, Audience 등
7. 면에 **태그 할당** (JBL 사용 시 그룹에도 태그 할당)
	1. 할당 할 태그만 눈 감기 해놓기
	2. 그룹 더블 클릭 후 태그 할당할 부분 선택
	X레이 / 카메라→원근감 해제 / 카메라→표준 뷰 활용
	3. 개체 정보에서 태그 바꾸기
	- → *반복*
	1. 태그 하나씩 눈감으며 전부 태그 할당 됐는지 확인
8. (d&b 시뮬레이션 시) 다각형을 **4각형 이하로** 쪼개기
9. 개체를 대칭 시키기 위해 원점에 기준이 될 육각형 생성
10. **대칭 개체 생성**
	`대칭할 개체 선택 → 대칭 이동 도구 선택+Ctrl → 기준 면 선택`
11. 전체 면 반전
	1. 전체 선택→우클릭→면 반전
	2. 확장 탭→JBL→JBL Model Edit→Reverse Faces
	3. 만약 면이 뒤죽박죽이라면? 
	- 면 하나 선택 후 우클릭→면 방향(R)
12. 시뮬레이션 파일 Export → 문제점 확인 및 수정

### 3. 시뮬레이션 파일 Export
- [[Sketchup to ArrayCalc]]
- [[Sketchup to Venue Synthesis]]


## Array Calc 파일 Export 시 유의 사항
- 저장할 폴더 경로에 한글 없어야함
- Export 파일 이름 영어로
- d&b는 4각형 까지만 인식 가능. 4각형 이하로 면 나눠주기
- 레이어(태그)만 지정해주면 같은 태그끼리 자동으로 묶이기 때문에, 굳이 그룹을 따로 지정해줄 필요 없음.
- 면에 지정된 태그로 인식됨

## Venue Synthesis 파일 Export 시 유의 사항
- 태그 별로 Plan Type을 정할 수 있음
- 면을 묶어주는(Join) 기능이 없으므로 태그를 정확하게 지정해줘야 함
- 그룹에 지정된 태그로 인식됨
	- 따라서 그룹을 지정했다면 그룹에 태그를 꼭 지정해줘야 함


## Q&A

**Q. 그룹은 왜 만들어야 하나요?**

A. 스케치업에서 그룹이 없으면 개체끼리 닿았을 때 서로 연결되어 구분이 어려워짐.
	또한 그룹 내에서 편집 시 주변이 흐릿하게 표시되므로 복잡한 모델에서도 편집이 용이함.
